# Code of Conduct

## Purpose

GPG Meister is a security-sensitive, local-first desktop project. The community should be practical, respectful, and careful with user trust.

This code of conduct applies to project spaces such as GitHub issues, pull requests, discussions, translation work, documentation, and direct project communication.

## Expected behavior

- Be respectful and constructive.
- Stay focused on the technical topic or contribution.
- Assume good intent, but accept corrections when wording or behavior causes problems.
- Give clear feedback without personal attacks.
- Be patient with new contributors, especially translation contributors and users reporting bugs.
- Treat security reports, private contact, and sensitive examples with care.
- Do not share private keys, passphrases, secrets, personal key material, or another person's private information.

## Unacceptable behavior

Unacceptable behavior includes:

- harassment, insults, threats, or intimidation
- discriminatory language or behavior
- sexualized comments or unwanted attention
- repeated off-topic disruption
- publishing private communication without consent
- exposing secrets, private key material, passphrases, or personal information
- pressuring maintainers to disclose security issues before they are assessed

## Security-sensitive discussions

If a topic may involve a vulnerability, leaked secret, private key material, decrypted content, or passphrase exposure, do not post full details publicly.

Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or block participants when behavior conflicts with this code of conduct.

When possible, maintainers will first give a clear warning and explain what needs to change. Severe or repeated behavior may lead to immediate action.
